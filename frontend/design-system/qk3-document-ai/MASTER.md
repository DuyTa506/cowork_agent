# QK3 Document AI — Design System (v2 "Hồ sơ")

Source of truth for every screen. Produced with the ui-ux-pro-max skill (style: Minimalism/Swiss, palette: "authority navy + trust gold", fonts: Vietnamese-first pairing) and then adapted to this product: an offline, dense, document-centric work tool for staff officers on a LAN. If a page file exists in `pages/`, it overrides this file.

## 1. Principles
1. **The document is the hero.** Paper (white sheet, Times New Roman, soft shadow) is the one skeuomorphic element; everything around it is quiet. Never decorate the chrome more than the document.
2. **Authority, not "AI product".** No sparkles, gradients, purple, glow, pill-shaped chat bubbles, emoji, or rounded-everything. Hairline borders and strong typographic hierarchy carry structure. The assistant is a *staff clerk's log*, not a chatbot toy.
3. **Everything states its type and status loudly.** File type (Word / PDF / DOC), secrecy level and processing state are always visible at a glance, with icon + label + colour (never colour alone).
4. **Dense but breathable** (density 7/10): 40–44 px table rows, 14 px UI text, 8 px grid. 
5. **Offline.** No CDN, no external fonts/icons/images. Fonts are bundled (`@fontsource`), icons are inline SVG (one consistent 1.75 px stroke set, 16/20 px).
6. Vietnamese first: diacritics must never clip (line-height ≥ 1.4 for UI text, ≥ 1.25 for headings), tabular figures for numbers/dates.

## 2. Tokens (defined in `src/styles/tokens.css`; never write raw hex in components)
Colour: ink `--ink-900 #0a1b36` (chrome), `--ink-800 #10284d`, `--ink-700 #1a3763`; brand/primary `--primary #1b3a8c` (hover `#142e73`, tint `--primary-tint`); brass accent `--brass #c9971c` (on dark) / `--brass-ink #8a5a0b` (text on light) / `--brass-tint`; neutrals `--bg #f3f4f7`, `--surface #fff`, `--surface-2 #f8f9fb`, `--line #e3e6ec`, `--line-strong #cbd1db`, text `--text #101828`, `--text-2 #3b4558`, `--muted #667085`; status (fg / bg tint / border): success `#157f4d`, warning `#a15c07`, danger `#b42318`, info `#1d4ed8`, neutral `#475467`. File types: Word `--ft-word #1e5bb8`, PDF `--ft-pdf #c0392b`, DOC (legacy) `--ft-doc #5b6b8c`, other `--ft-other`.
Radius: `--r-xs 4px`, `--r-sm 6px` (controls), `--r-md 10px` (cards/panels), `--r-lg 14px` (modals, composer). Never > 14 px except avatars/dots.
Shadow: `--sh-1` hairline lift, `--sh-2` popover/drawer, `--sh-paper` document sheet.
Spacing scale 4/8/12/16/24/32/48. Focus ring: 2 px `--primary` + 2 px offset, always visible. Motion: 120 ms (hover/focus), 200 ms (drawer/panel), `ease-out`, never > 250 ms; honour `prefers-reduced-motion`.

## 3. Typography (bundled)
* UI + body: **Be Vietnam Pro** 400/500/600/700 (designed for Vietnamese). Base 14 px/1.5; table cells 13.5 px; captions 12.5 px (never smaller than 12 px); buttons 14 px/600.
* Display/page titles & brand wordmark: **EB Garamond** 600 (24/30 page title, 20/26 section title, brand 18 px letter-spaced caps). Use serif only for titles, empty-state headlines and the brand — never for controls or table text.
* Document surfaces (viewer, canvas, preview): Times New Roman 13–14 px — it is the real document.
* Section labels: Be Vietnam Pro 600, 11.5 px, uppercase, letter-spacing .06em, `--muted`.
* Numbers/dates/codes (số ký hiệu): `font-variant-numeric: tabular-nums`.

## 4. Core components
* **Button**: primary (navy fill, white text), secondary (white, line-strong border), ghost, danger. Height 36 (32 compact), radius `--r-sm`. Icon+label for primary actions. Disabled = 45 % + `aria-disabled`.
* **FileTypeBadge** (new, shared): 32×40 px mini "page" glyph with folded corner, 11 px bold extension label (DOCX / DOC / PDF) in the file-type colour on a tint — used in the document table, drawer header, attachments, citations, upload dialog. Small variant 20×24 for inline. Legacy `.doc` is visibly different from `.docx`.
* **StatusChip** (replaces tiny dots): height 26, 13 px/600 text, icon + label, tinted background + border: Sẵn sàng (success, check), Đang xử lý (info, animated ring, `aria-busy`), Chờ xử lý (neutral, clock), Cần rà soát (warning, eye), Cần OCR (warning, scan), Lỗi (danger, alert). Secrecy: **Mật** chip (danger-solid, lock icon) vs **Thường** (neutral outline).
* **Table**: sticky header 40 px with section-label style, rows 44–52 px, hover `--surface-2`, selected row has 3 px brass left bar + primary tint, zebra none, numeric columns right-aligned/tabular. Row actions appear as a kebab and on hover.
* **Drawer** (right, 440–480 px, 200 ms slide): header (type badge + title + status chip + close), tabs underlined with 2 px brass, sticky footer actions.
* **Form field**: label above (12.5 px/600 `--text-2`), control 36 px, helper/error below in 12.5 px; required marker; error uses border + icon + text.
* **Toast/Alert**: left 3 px status bar, icon, title + body; `role=status`/`alert`.
* **Empty state**: serif headline, one-line explanation, one primary action; no stock illustration.

## 5. Shell
Left rail 232 px `--ink-900` (collapses to 64 px icon rail ≤ 1100 px): brand block (logo 36 px + "QUÂN KHU 3" EB Garamond brass caps + "Hệ thống AI xử lý văn bản"), nav items 40 px with 20 px icons, active = `--ink-700` bg + 3 px brass bar + white text; bottom: network-status chip ("Mạng nội bộ") and user card with role. Main area: top bar 56 px (page title as serif, optional breadcrumb, **global search / command palette `Ctrl+K`**: navigate pages + search documents by title/số ký hiệu, user menu). Content padding 24 px; max width fluid.

## 6. Screens
**Login**: split screen. Left 46 % `--ink-900` with a faint guilloche/star line pattern (SVG, low opacity), logo, serif headline "Hệ thống AI xử lý văn bản", three trust lines (Chạy trong mạng nội bộ · Phân quyền theo đơn vị · Nhật ký kiểm toán). Right: form card, large inputs (44 px), clear error message, "Quên mật khẩu → liên hệ quản trị viên".
**Kho văn bản**: title + description + [Tải nhiều tệp] [Tải văn bản lên]. Below: *stat strip* of 4 clickable cards (Tất cả / Sẵn sàng / Đang xử lý / Cần xử lý: number 24 px/600 + label + status colour bar) that act as the state filter (replaces underline tabs). Filter bar: wide search, Loại văn bản, Đơn vị (tree), Mức độ, Ngày ban hành range, "Xóa bộ lọc". Table columns: [file-type badge + Trích yếu (bold) / Số ký hiệu · Loại (muted)] · Đơn vị · Ngày ban hành · Mức độ chip · Trạng thái chip · kebab. Drawer: **Xem trước first** (mini paper with highlight), then Thông tin (editable fields grouped: Nhận dạng / Ban hành / Tệp), then Tiến trình (vertical stepper with durations).
**Kiểm tra thể thức**: header; empty state = large dropzone card with file-type badges + 3-step strip (Chọn tệp → Xem kết quả → Sửa & tải về) and an options card (bộ luật, soát chính tả). Result: verdict bar (file badge + name + pages + "đạt / chưa đạt" headline in serif, severity counts as segmented filter buttons: Bắt buộc 18 · Cảnh báo 9 · Chính tả 8 · Lưu ý 2, each ≥ 32 px high with count), two columns — findings list (compact rows: severity icon, rule title, 1-line detail, expand for "Hiện có / Cần sửa", checkbox for auto-fixable, "Tự sửa" tag) and sticky paper preview with marked paragraphs; sticky bottom action bar (Sửa N mục · tải bản sửa · ghi chú · báo cáo · lưu kho).
**Trợ lý AI** (must NOT look like a generic chatbot): three zones — sessions list (240 px, grouped Hôm nay / Tuần này / Cũ hơn, hairline rows), conversation (single column, max 780 px, centred), optional Canvas (≥ 46 % width, paper page). Conversation is a **log of entries**, not bubbles: each entry has a small role label ("ĐỒNG CHÍ" / "TRỢ LÝ AI") in section-label style with time, a 1 px hairline above, no avatars, no bubble backgrounds. User entries: text in 15 px `--text`, attachments as FileTypeBadge chips. Assistant entries: a collapsible "Nhật ký xử lý · 3 bước · 2,1 giây" strip (steps as compact rows with status glyphs; running ones pulse), then the answer typeset in 15 px/1.7 with inline citation markers as small square superscripts `[1]` (brass), lists/tables styled like a document, and a **"Nguồn trích dẫn" footer**: numbered cards, each with FileTypeBadge + title + số ký hiệu + đơn vị + section, click opens the source preview. Actions under an answer: Sao chép · Tạo lại · Mở trong Canvas. Empty state: serif greeting "Đồng chí cần tra cứu, tóm tắt hay soạn thảo văn bản?" + 4 starter rows (not cards with emoji): Tra cứu văn bản · Tóm tắt văn bản · Soạn công văn/kế hoạch (activates Canvas) · Kiểm tra thể thức. Composer: 14 px radius, 1 px `--line-strong` border, focus ring; toolbar row below the textarea with [+] menu (Tải tệp lên · Canvas), chips (Canvas ×, attachments with FileTypeBadge + state), right-aligned Send (navy, square-ish 36 px) / Stop; footer note "Trợ lý AI có thể nhầm. Hãy đối chiếu nguồn trích dẫn trước khi dùng." (12.5 px muted).
**Canvas**: toolbar (template name + TT68 chip + "Phiên bản n · Đã lưu" ), paper page 794 px wide scaled to fit, owner styling (system dotted underline `--muted`, assistant `--brass-tint` background, user dashed `--primary`), proposal diff (del red strike / ins green tint) with Chấp nhận / Từ chối; right tabs: Kiểm tra thể thức · Lịch sử.
**Quản trị**: left sub-nav (Tài khoản · Hệ thống · Nhật ký), tables as Kho; settings sections as cards with section header, helper text, "Kiểm tra kết nối" inline result chip, secret field state "Đã đặt · Đổi · Xóa".

## 7. Accessibility checklist (blocking)
Contrast ≥ 4.5:1 text / 3:1 UI; visible focus on every control; hit targets ≥ 36 px (44 px on touch ≤ 900 px); icon-only buttons have `aria-label` + tooltip; status never by colour alone; live regions for upload/processing/streaming; keyboard: Ctrl+K, Esc closes drawers/menus, Enter sends, arrow keys in tabs/menus; tables with `scope` headers; reduced motion respected; works at 1440, 1100, 900 and 720 px without horizontal scroll.

## 8. Chat patterns (ui-ux-pro-max: AI-Native UI + Minimalism/Swiss, adapted — NOT the stock "AI purple + bubbles" look)
Adopt: minimal chrome; sticky composer; "context cards" with a 3 px left accent for tool activity and sources; typing/working indicator that shows *what* is happening (named steps, not a generic 3-dot loader); label AI content as AI (role label + disclaimer line); feedback loop under each answer (Hữu ích / Chưa đúng, Tạo lại, Sao chép); helpful empty state with guided starters; readable measure (65–75 ch ≈ 780 px max); auto-scroll that stops when the user scrolls up and offers a "↓ Tin mới" jump button; streaming-style reveal of the answer (the backend delivers the answer whole after the steps, so reveal progressively by word groups, skippable by click, instant under reduced motion).
Reject: purple/indigo accent, gradient avatars, sparkle icons, rounded speech bubbles with tails, emoji reactions, glassmorphism, typing-dots-only loaders, auto-playing animations that cannot be paused.
Structure recap: entries separated by hairlines (role label + time), no bubbles; steps in a "Nhật ký xử lý" strip of context cards; answer typeset like a document; "Nguồn trích dẫn" footer cards with FileTypeBadge; composer = bordered card with toolbar row.
